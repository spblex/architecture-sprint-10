# Аудит безопасности данных Медикаменте

## Список проблемных зон
| №  | Описание проблемы                                                                       |
|----|-----------------------------------------------------------------------------------------|
| 1  | Ручной ввод данных на всех этапах                                                       |
| 2  | Отсутствует шифрование персональных данных                                              |
| 3  | Отсутствует аудит действий пользователей в системах                                     |
| 4  | Отсутствует аудит доступа к персональным данным пациентов                               |
| 5  | Отсутствует журналирование изменений данных                                             |
| 6  | Отсутствует RBAC доступа к данным пациентов - данные всех пациентов в одном хранилище   |
| 7  | Использование Excel для хранения персональных данных                                    |
| 8  | Нет контроля над обменом данных между внутренними системами                             |
| 9  | Инфраструктура не рассчитана на резкий рост объема обрабатываемых данных                |


## Данные для защиты
| Тип данных                                                       | Метод защиты                                  |
|------------------------------------------------------------------|-----------------------------------------------|
| Персональные данные пациентов                                    | Шифрование, RBAC                              |
| Результаты приема пациента у доктора                             | Шифрование, RBAC, Обезличивание для аналитики |
| Финансовые данные                                                | Шифрование, RBAC                              |
